# ConfAI 2026

**Title:** Literature Discovery with Multi-Signal Ranking and Citation-Grounded RAG  

**Author:** Ajay Sharma · M.S. in AI, Plaksha University  
**Supervisor:** Dr. Subrat Panda · AI in Practice extended track  

**Live demo:** https://nataltiger26-arxiv-paper-suggester-rag-srcapp-olkakz.streamlit.app/  
**Code:** https://github.com/NatalTiger26/ArXiv_Paper_Suggester-RAG  

## Scope (what the conference story is)

1. Multi-signal **ranking** of arXiv papers for a free-text research interest  
2. **Selective full-text ingest** (PDF → Markdown → chunk → embed)  
3. **Citation-grounded RAG** (retrieve passages → generate with sources + coverage cue)  
4. **CLI + Streamlit**, local embeddings, evaluation protocol and honest limits  

Poster print materials (if present): `docs/confai/`.

## What visitors should try

1. Rank papers for an interest in the UI or CLI  
2. Ingest a few top IDs  
3. Ask a precise question and inspect citations  

For setup and commands, see the root [README.md](../README.md) and [WORKFLOW.md](../WORKFLOW.md).
