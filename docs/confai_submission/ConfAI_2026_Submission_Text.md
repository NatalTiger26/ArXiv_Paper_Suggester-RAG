## 1. Project Title

**Literature Discovery with Multi-Signal Ranking and Citation-Grounded RAG**

*Subtitle* :  Personalised arXiv recommendation, selective full-text ingest, and grounded question answering

---

## 2. Project Info (≤ 250 words)


Researchers need both *discovery* and *use* of papers: ranked lists alone lack personalisation, while chat models often answer without faithful sources. This project builds an end-to-end literature assistant for that gap. A multi-signal recommender ranks arXiv papers for a free-text research interest using semantic similarity, recency, citation impact, and author continuity, with inspectable weight presets. Selected papers are ingested on demand—PDF to Markdown (with OCR when needed), section-aware chunking, and local embeddings (EmbeddingGemma 2; a lighter MiniLM path on constrained cloud hosts)—into a Chroma vector index. Users then ask questions and receive answers generated by Gemini with explicit paper-level citations and coverage notes when evidence is thin.

The system ships as both a CLI (for batch jobs and diagnosis, managed with uv) and a Streamlit web app (library, recommend, ingest, ask). Evaluation follows AI in Practice practice: a gold set of about one hundred questions, MRR, Recall@k, Hit@1, bootstrap confidence intervals, embedding-dimension sweeps, latency, and refusal behaviour. On a curated full-text index, representative runs reached mean MRR about 0.75 (95% CI roughly 0.66–0.83) and Recall@k about 0.85, with citation index validity about 0.95. Limits are reported honestly—especially refusal calibration and dependence on which papers are fully ingested. Developed under Dr. Subrat Panda as an AI in Practice extended track, the work is proposed for a ConfAI 2026 poster with a live demo.
